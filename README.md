## Çfarë realizova

Krijova një pasaportë digjitale për një personazh të sajuar
që kandidon si udhërrëfyes i kampusit.

Projekti përmban:
- index.html
- rreth.html
- kontakt.html
- lidhje relative ndërmjet faqeve
- README.md
