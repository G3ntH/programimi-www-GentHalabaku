# Java II – Muzeu i gjerave

## Çfarë realizova
Krijova një faqe web për një muze me tri ekspozita:
- Çelësi
- Filxhani
- Bileta

Përdora HTML dhe CSS, navigim me lidhje
dhe elementin details për historitë.

## Si hapet
Hapet skedari index.html përmes Live Server
në VS Code apo nëpermjet index nga browser (e gjetur ne file)

## Hyrjet dhe daljet
Hyrjet: klikimi i lidhjeve dhe hapja e historive.
Daljet: navigimi te ekspozitat dhe shfaqja e historive.

## Testet
1. Hapja e faqes: tri kartat shfaqen.
2. Navigimi: lidhjet kalojnë te seksionet.
3. Historia: details shfaq përmbajtjen.
4. Ekrani i ngushtë: kartat vendosen vertikalisht.

## Rastet kufitare
- Ekran i ngushtë: kartat përshtaten në një kolonë.
- Historia e hapur: teksti shfaqet brenda kartës.

## AI dhe burimet
Është përdorur AI si ndihmë për kodin dhe
shpjegimin e HTML dhe CSS.
